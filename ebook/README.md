# 존중시민 웹북 (청소년편 · 성인편)

부천여성청소년재단 부천시일·쉼지원센터 / 감정노동 상호존중 시민문화 캠페인 「부천다움」

모니터에서는 책장을 넘기듯 양면으로 펼쳐지고, 폰에서는 한 장씩 넘어간다.
빌드 도구 없이 정적 파일만으로 동작한다.

## 구조

```
ebook/
  assets/
    page-flip.browser.js   StPageFlip v2.0.7 (MIT) — 책장 넘김 엔진
    page-flip.LICENSE.txt
    book.css               두 책 공용 스타일
    book.js                두 책 공용 동작
  youth/
    index.html             쪽 목록(window.BOOK)만 다르다
    pages/01~12.webp
  adult/
    index.html
    pages/01~12.webp
```

새 책을 추가하려면 폴더 하나를 더 만들고 `index.html`의 `window.BOOK.pages`만 바꾸면 된다.

## 화면 전환 기준

`book.js`의 `minWidth: 380` 이 기준이다. 책이 놓인 영역이 **760px보다 넓으면 양면 펼침**,
좁으면 한 장씩으로 자동 전환된다.

## 기능

- 모서리를 끌거나 눌러서 넘기기, 좌우 화살표 버튼, 키보드 ←→
- 목차에서 원하는 쪽으로 이동
- 크게 보기(돋보기) — 현재 쪽을 화면 폭에 맞춰 스크롤하며 읽는다. 폰에서 말풍선 읽을 때 쓴다
- 전체화면 (모니터 전용)
- URL 해시로 특정 쪽 열기 — `#7`
- 자동 넘김 — ▶ 버튼, 속도 4s / 6s / 9s / 14s, 스페이스바로 재생·정지

### 상영용 URL

| 주소 | 동작 |
| --- | --- |
| `?auto=1` | 열자마자 6초 간격 자동 넘김, 마지막 쪽에서 정지 |
| `?auto=1&speed=9` | 9초 간격 |
| `?auto=1&loop=1` | 뒷표지 다음에 표지로 돌아가 무한 반복 |

## 쪽 이미지 규격

12쪽 모두 **1055 × 1491px** (A4 비율)로 맞춰야 책장 넘김이 어긋나지 않는다.
성인편 원본 중 p2·p3·p12는 1024×1536이라, 그림을 자르거나 늘리지 않고
좌우에 각 페이지의 배경색 여백을 더해 비율을 맞췄다.
